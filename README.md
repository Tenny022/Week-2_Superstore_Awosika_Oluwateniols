# Executive Sales Performance Dashboard

An interactive Power BI dashboard that helps management track sales, profit, customer behaviour and regional performance.

## Overview
- **Data:** Superstore retail orders, 2014 to 2017 (5,009 orders)
- **Tools:** Power BI (Power Query and DAX)
- **Pages:** Executive Overview and Product Analysis

## Key Results
- Total Sales: $2.3M
- Total Profit: $286.4K
- Profit Margin: 12.5%
- Strongest region: West. Weakest margin: Central (7.9%)
- Furniture earns only a 2.5% margin
